# Data dictionary

All files are generated by `pipeline/` into `data/processed/`. Every row carries `source_file`.

## sequence_catalog.csv — one row per image folder
| Column | Meaning |
|---|---|
| sequence_id | `{group}-{camera}-{variant}-{format}-{partN or single}`, e.g. `S1-C2-raw-jpeg-part1` |
| group, camera | folder labels from the inventory (meaning **not documented**) |
| file_type | inventory label: Raw JPEG, Mapped JPEG, ICMAD PNG, Mapped TIFF, BIT |
| processing_variant | raw, mapped, icmad, bit |
| part | part number in the folder name, empty if none |
| folder | original folder name |
| n_files | frames listed in the inventory |
| first_raw_id, last_raw_id | min / max raw_id |
| duration_s | (last − first) / 1000 |
| median_diff_ms, min_diff_ms, max_diff_ms | stats of consecutive raw_id differences |
| duplicates | repeated raw_id count |
| n_gaps_gt_2x | intervals larger than 2 × median |
| temporal_quality | continuous, gap_detected, overlapping_variant, incomplete, unknown |
| sequence_role | primary, processing_variant, bit_sequence |
| calibration_file | distortion grid for the same group+camera, if any |

`temporal_quality` precedence: gap_detected > overlapping_variant > incomplete (missing files) > continuous.

## frame_catalog.csv — one row per frame
| Column | Meaning |
|---|---|
| frame_id | `{sequence_id}-f{frame_index:05d}` |
| raw_id | numeric id in the file name; primary ordering field |
| frame_index | 0-based position after sorting by raw_id |
| time_s | (raw_id − first raw_id of the sequence) / 1000 |
| relative_path | `folder/file_name`, relative to the raw data folder |
| availability | available, missing (folder exists, file absent), path_only (folder absent) |
| warning | `;`-separated: `gap_before:<s>`, `duplicate_raw_id`, `asset_missing`, `asset_path_only` |

## calibration_catalog.csv — one row per (grid, linked sequence)
| Column | Meaning |
|---|---|
| calibration_id | `CAL-{group}{camera}[-{sequence_id}]` |
| reference_length_mm | from the file name (`30mmBlock`); empty if not stated |
| calibration_status | validated, pending, unavailable — currently never validated |

## frame_metrics.csv — long format, one row per (frame, metric)
| Column | Meaning |
|---|---|
| metric_name | mean_intensity, bright_pixel_fraction, bright_area_pixels, centroid_x, centroid_y, bbox_width_pixels, bbox_height_pixels |
| unit | intensity_0_255, fraction, pixels, px |
| method | grayscale conversion + fixed threshold |
| threshold | 128 (empty for mean_intensity) |
| confidence | high (direct statistic), medium (threshold-dependent area), low (geometry) |
| source_file | the image path the value was computed from |

Sampling: every 5th frame plus the first frame after each gap and the last frame. Geometry metrics are omitted when no
pixel reaches the threshold.

## scientific_reference_results.json
Values transcribed from urban2019 with page numbers. Label: *Published reference*.
